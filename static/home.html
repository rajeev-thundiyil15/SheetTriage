Three ways to run it

You choose before it starts. Most people use the middle one.

Audit only

To see how messy a file is

Nothing is changed. You get a list of every problem.

Clean + report

For most files

Safe fixes are made. Everything else is flagged, and every row stays in the file.

Strict clean

When the file must be fully clean

Safe fixes are made, and rows that still have problems are left out of the cleaned file. They're kept in the error report, so nothing is lost.

Questions

Why didn't it fix everything?

Because some fixes would be guesses. If an email is blank, or a price says "call for price", there's no way to know the right value from the file. SheetTriage marks these for you rather than inventing something that looks right but isn't.

What do I do with the flagged rows?

Each one says what's wrong. Correct them in your original spreadsheet and run it again, or, if a flagged value is actually fine (say you've started accepting a new payment type), add it to the allowed values on the rules page.

Will it delete my data?

No. Every row stays in the cleaned file unless you choose Strict clean, and even then the left-out rows are listed in the error report. Your original file is never changed.

Who can see my file?

Only you. Without signing in, results are kept for an hour in your browser. Sign in to keep them for 7 days. The AI assistant is sent your column names, the first few rows and the values that break a rule, not the whole file. The privacy page has the details.

What does it cost?

Nothing to try: you get 3 runs a day for free, with or without an account.

What files can I use?

Spreadsheets saved as CSV, up to 5 MB and 30,000 rows. Files from Excel work, including ones that use semicolons. Please don't upload card numbers, ID numbers or health records.
